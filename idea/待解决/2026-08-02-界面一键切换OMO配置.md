# 界面一键切换 OMO slim 配置

- 创建日期：2026-08-02
- 优先级：中

## 背景 / 痛点

- 用户使用 oh-my-opencode-slim（OMO slim）插件，需要经常切换配置（preset，即一组"哪个智能体用哪个模型"的组合）。
- 终端里 `/preset` 是 OMO slim 插件提供的命令（不是 OpenCode 官方命令）：它本质是修改配置文件 `oh-my-opencode-slim.json(c)` 里的 `preset` 字段，**改完必须重新加载/重启 OpenCode 服务才真正生效**。
- 当前界面里无法完成切换配置，只能 SSH 到服务器 → 打开终端跑 `/preset` → 再重启服务，非常麻烦。

## 期望效果

- 界面设置页能直接列出 OMO slim 配置里已有的 preset（如 openai、opencode-go 等），下拉选择即可切换。
- 选定后自动完成：修改配置文件里的 `preset` 字段 → 重启服务 → 生效。效果等同终端 `/preset` + 重启，但全程不用 SSH。
- 重启部分复用"一键重启服务端"需求的能力。

## 验收标准

1. 设置页能看到当前正在用的 preset 名称，以及全部可选的 preset 列表。
2. 选择另一个 preset 后，配置文件里的 `preset` 字段被正确更新（可在服务器上验证文件内容）。
3. 服务自动重启，新 preset 生效（各智能体实际使用新 preset 里的模型）。
4. 全程不用 SSH。
