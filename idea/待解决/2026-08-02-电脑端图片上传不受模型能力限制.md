# 电脑端图片上传不受模型能力限制

- 创建日期：2026-08-02
- 优先级：高

## 背景 / 痛点

- 手机端可以上传图片，电脑端却看不到上传按钮（回形针📎），也不能 Ctrl+V 粘贴图片。
- 查代码后发现：界面规定"只有当前选中的模型支持看图时，才显示上传按钮"。电脑上当前用的模型不支持图片，按钮就整个消失了（不是电脑端被刻意砍掉功能）。
- 但 OMO slim 智能体可以把图片转给识图模型处理，所以"当前模型不支持图片"这个限制其实没必要。

## 期望效果

- 电脑端不管当前模型支不支持图片，都能看到上传按钮、都能上传图片、都能 Ctrl+V 粘贴图片。
- 图片发出后，由 OMO slim 智能体调用识图模型识别（而不是被当前模型能力卡住）。
- 手机端行为保持不变。

## 验收标准

1. 电脑上选中一个"不支持图片"的模型，聊天输入框里仍能看到回形针按钮。
2. 用这个模型也能上传图片 / 粘贴图片，能正常发出。
3. AI 能"看"到图片并正确回答图片内容（由识图模型处理）。
4. 手机端上传图片功能不受影响。
