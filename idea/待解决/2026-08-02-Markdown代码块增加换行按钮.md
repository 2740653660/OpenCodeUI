# Markdown 代码块增加换行按钮

- 创建日期：2026-08-02
- 优先级：中

## 背景 / 痛点

- 当前消息界面中的 Markdown 代码块，如果某一行内容太长，就会超出代码框宽度。
- 用户需要左右滚动才能查看完整代码，阅读长命令、长路径、配置内容或长字符串时不方便。
- 项目虽然已经有代码块自动换行能力，但用户目前不能直接在代码框工具栏中快速切换，只能通过其他设置进行调整。
- 当前代码框右上角已有复制按钮，适合在复制按钮旁边增加换行控制。

## 期望效果

- 在 Markdown 代码块的工具栏中增加一个换行按钮。
- 换行按钮放在复制按钮的左边。
- 换行功能默认开启，让代码块优先适应当前窗口宽度，避免用户一打开就需要左右滚动。
- 点击换行按钮后，可以在“自动换行”和“横向滚动”两种显示方式之间切换。
- 换行按钮控制消息界面中的所有 Markdown 代码块，而不是只控制当前点击的代码块。
- 用户关闭换行功能后，记住用户的选择，下次打开页面或应用时继续保持上次的状态。
- 换行开关状态与现有代码块自动换行设置保持一致，避免出现多个互相矛盾的换行设置。
- 代码内容本身不能被修改，复制按钮复制出的内容仍然保持原始格式。

## 验收标准

1. 消息界面的 Markdown 代码块工具栏中，复制按钮左侧有换行按钮。
2. 第一次使用或没有保存过设置时，代码块默认开启自动换行。
3. 默认开启换行后，超出代码框宽度的长代码行会自动折行，不需要左右滚动。
4. 点击换行按钮后，所有 Markdown 代码块都能在自动换行和横向滚动之间切换。
5. 关闭换行后，长代码行可以通过左右滚动查看完整内容。
6. 用户关闭换行后重新打开页面或应用，仍保持关闭状态。
7. 用户重新开启换行后，重新打开页面或应用仍保持开启状态。
8. 换行按钮的位置在复制按钮左边，两个按钮在视觉和操作上属于同一组代码框工具栏。
9. 点击换行按钮不会改变代码内容。
10. 点击复制按钮复制的仍是未改变格式的原始代码文本。
11. 代码块的语法高亮、代码滚动、最大高度限制等原有功能不受影响。
12. 没有代码语言标签的 Markdown 代码块也能正常显示和使用换行按钮。
