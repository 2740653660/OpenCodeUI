# idea/ 文件夹说明

这里是我（使用者）的个人需求想法区。本文件夹随 fork 的 git 管理，但**绝不进入发往上游的 PR**。

## 怎么用

- **有新想法**：直接跟 AI 助手说"我想……"，AI 会先问清楚、复述确认后，按模板在 `待解决/` 里建一个需求文件。
- **想解决某个需求**：跟 AI 说"解决 `待解决/` 里的 XXX"，AI 会按规则走完整流程（见 `AGENTS.md`）。
- **需求状态**：待解决 → 解决中 → 已解决 / 已放弃（把文件移动到对应文件夹即可，用 git mv）。

## 目录

| 文件夹 | 用途 |
| ------ | ---- |
| `待解决/` | 新想到、还没开始做的需求 |
| `解决中/` | 正在解决的需求 |
| `已解决/` | 已完成的需求（含解决记录） |
| `已放弃/` | 决定不做 / 做不到的需求 |
