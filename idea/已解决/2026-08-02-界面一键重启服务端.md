# 界面一键重启服务端

- 创建日期：2026-08-02
- 优先级：中

## 背景 / 痛点

- 修改文件、添加模型、修改 OpenCode 设置后，必须重启服务器上的 OpenCode 服务（opencode serve）才会生效。
- 当前界面（OpenCodeUI）没有任何重启入口，只能自己通过 SSH 连接到服务器手动重启，很麻烦。
- 查代码确认：项目是纯前端，没有重启远程服务的按钮或接口（桌面版 Tauri 只能管理本机进程，用户是远程 Web 场景用不上）。

## 期望效果

- 界面里（比如设置页）加一个"重启服务"按钮，点一下自动重启远程服务，重启后界面自动重连、配置生效，全程不用 SSH。
- 由于不同用户管理服务的方式不同（Docker / systemd / 手动进程），按钮执行的**重启命令做成可配置**：用户可在设置里填自己的重启命令（如 `docker restart xxx` 或 `systemctl restart opencode`），这样功能可以开源给所有人用。
- 不依赖具体服务管理方式，尽量用项目已有的能力（如 PTY 终端接口）执行命令。

## 验收标准

1. 设置页有"重启服务"按钮，能填自定义重启命令。
2. 点击按钮 → 远程服务重启 → 界面自动重连 → 新配置生效，全程不用 SSH。
3. 按钮有明确的"正在重启 / 成功 / 失败"提示。

- 解决日期：2026-08-02
